# Assets

Static files for the setup (wallpapers, screenshots, etc.).

`wallpaper.svg` is the editable source for the project's original lakeside pagoda artwork.
`wallpaper.png` is the 2560x1440 raster installed by `setup/wallpaper.sh`.

The image uses the Rosé Pine Moon palette and was created specifically for this repository from original vector shapes.
It contains no third-party artwork or externally licensed assets.
